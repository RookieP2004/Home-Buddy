## 🔧 Quick Reference

### Primary Colors
```css
Primary Red:    #EF4F5F  (Main CTAs, emphasis)
Accent Orange:  #FF6B35  (Secondary, gradients)
Background:     #FFFFFF  (Clean foundation)
Foreground:     #0F0F0F  (Deep black text)
```

### Tailwind Classes
```css
/* Colors */
bg-primary    → Red background
text-primary  → Red text
bg-accent     → Orange background
text-accent   → Orange text

/* Gradients */
from-primary to-accent          → Red to Orange
from-primary via-accent         → Red through Orange
to-primary                       → End with Red

/* Components */
rounded-2xl   → Card radius
border-border → Standard border
shadow-lg     → Hover shadow
p-8           → Standard padding
gap-6         → Standard gap
```
